# CP1 - Chat Firebase

Aplicativo de chat desenvolvido em React Native com TypeScript utilizando Firebase Authentication e Firebase Realtime Database.

O projeto permite autenticação de usuários e comunicação em tempo real entre duas pessoas, respeitando as regras de compatibilidade entre os diferentes provedores de autenticação.

## Tecnologias

- React Native
- Expo
- Expo SDK 55
- TypeScript
- Firebase Authentication
- Firebase Realtime Database

## Funcionalidades

- Cadastro com e-mail e senha
- Login com e-mail e senha
- Login com Google
- Login com Apple
- Logout
- Listagem de contatos compatíveis
- Conversas 1 para 1
- Mensagens em tempo real
- Persistência das mensagens no Firebase Realtime Database
- Tratamento de loading e erros

## Serviços Firebase

O projeto utiliza:

- Firebase Authentication
- Firebase Realtime Database
